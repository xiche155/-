## 📖 简介

**速讯助手** 是一款专为 QQ、微信、抖音等平台设计的本地自动化消息发送工具。软件采用现代化的 UI 设计，支持动态视频背景与毛玻璃半透明质感，操作直观，功能强大。所有操作均在本地完成，保障您的数据隐私。

> ⚠️ **当前版本状态：** 内部测试版 (Beta)。部分功能可能仍在优化中，内测版本包含到期时间限制。

---

## ✨ 核心功能

- **📱 多平台支持**：完美适配 QQ、微信、抖音的文字群发。
- **💬 QQ空间专属模式**：支持 QQ空间评论发送，自动重试，防封控。
- **🖼️ 图片批量发送**：支持将图片快速复制到剪贴板并批量发送，可自定义发送间隔。
- **🎮 游戏模式**：专为游戏内聊天设计，支持自定义发送键（Enter/T/Y等），Ctrl+V 极速粘贴发送。
- **📚 消息库系统**：自定义模板，一键应用。支持分类管理，发送前快速调用。
- **📢 艾特模式**：支持按昵称列表批量艾特，微信平台支持纯艾特发送（不带内容）。
- **🎨 沉浸式 UI**：告别传统“窗口”时代，支持视频动态背景、半透明卡片 UI、无边框拖拽缩放。
- **🔄 自动更新**：内置基于 GitHub Releases 的自动检查更新与无缝替换升级。

## 🛠️ 使用说明

1. **启动软件**：双击运行 `速讯助手.exe`。
2. **选择平台**：在左侧菜单选择你需要发送消息的平台（如 QQ文字）。
3. **输入内容**：输入你要发送的文本或设置好模板。
4. **设置参数**：调整重复次数、发送间隔（秒）、准备时间等。
5. **开始发送**：点击“开始发送”，在倒计时结束前，**将鼠标手动点击到目标聊天窗口的输入框内，并保持鼠标不动**。
6. **终止发送**：发送过程中可随时点击“停止”按钮中断任务。

*(提示：如果使用图片发送，可以直接将图片文件拖拽到软件的图片列表区域)*

## 💻 技术栈

- **后端语言**：Python 3.10+
- **GUI 框架**：PySide6 (Qt 6)
- **UI 描述**：QML (Qt Quick)
- **自动化库**：`pyautogui`, `pyperclip`, `win32clipboard`

## ⚠️ 注意事项

1. **安全软件拦截**：由于软件涉及模拟键鼠操作，部分杀毒软件可能会误报，请添加信任。
2. **发送频率**：请合理设置“间隔(秒)”，间隔过短极易导致账号被平台风控限制或封禁。
3. **运行环境**：建议在 Windows 10/11 系统下运行。
4. **鼠标控制**：发送过程中，**绝对不要移动鼠标或点击其他窗口**，否则会导致消息发送到错误的地方。
